# Audio Player (Static)

Simple static audio player for your WAV file, ready for GitHub Pages.

## Files

- `index.html`
- `styles.css`
- `app.js`
- `Aadhi Aadhi_FINAL_MASTER_48Khz_16BIt_07_.wav`

## Run locally

Open `index.html` directly in your browser.

## Deploy on GitHub Pages

1. Push to GitHub.
2. Open repo **Settings** -> **Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main` and folder: `/ (root)`.
5. Save and wait for Pages URL.

## Important

This is a static app. Any access code in `app.js` is visible to users and is not truly secure.
